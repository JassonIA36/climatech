# ClimaTech Valle ❄️

Landing page y plataforma web de servicios técnicos de climatización e ingeniería térmica en **Guadalajara de Buga y el Valle del Cauca, Colombia**.

## 📌 Características Principales
- **18 Años de Experiencia:** Enfoque en instalación certificada, mantenimiento preventivo y reparación técnica de aires acondicionados Mini Split y sistemas Inverter.
- **Identidad de Marca:** Logotipo vectorial profesional y responsive (`assets/logo.svg`).
- **SEO Local Completo:**
  - Optimizado para búsquedas en Guadalajara de Buga, Tuluá, Palmira, Cali y municipios del Valle.
  - Metadatos Open Graph y Twitter Cards.
  - Datos estructurados Schema.org (`HVACBusiness` y `FAQPage`).
  - Archivos `sitemap.xml`, `robots.txt` y página de error `404.html`.
- **Calculadora Interactiva de BTU:** Estimación en tiempo real del equipo requerido según área (m²) y tipo de espacio.
- **Canales de Contacto Directo:** Enlace a WhatsApp directo y llamadas telefónicas (`+57 323 942 1252`).
- **Galería Interactiva:** Fotografías reales de instalaciones y mantenimientos técnicos con visor modal (lightbox).

## 🚀 Tecnologías
- HTML5 semántico
- CSS3 / Tailwind CSS (vía CDN)
- JavaScript Vanilla
- Google Fonts (Manrope, Space Grotesk) & Material Symbols

## 🌐 Publicación / Despliegue
Este repositorio está listo para ser alojado directamente en **GitHub Pages**, **Vercel**, **Netlify** o cualquier servidor web estático.
